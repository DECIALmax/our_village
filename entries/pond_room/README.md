# 听水居 · 池塘花园卧室

入口：`res://entries/pond_room/entry.tscn`，在 Godot 中打开后按 F6 运行当前场景。

使用博物馆原始石砌池塘、水面与睡莲素材，搭配木地板、卧室、阅读区、茶桌、钓鱼角和植物。池塘及家具设有实体碰撞，导航避开障碍，角色沿池塘周边巡游。底部门垫通往同目录的玄关，玄关右侧门垫返回房间。

NPC 已换成你的 `lan.png` 角色，角色名和作者沿用 `meta.json` 中的「听水」和「烂」。台词在 `dialogue.json` 修改。

角色原始导出为 896×640 RGBA、每帧 16×32，原图保留在角色生成器的 Saved Characters 目录。项目中仅保留适配后的 `char/sheet.png`：精确 3 倍最近邻整数放大至 2688×1920、每帧 48×96，不裁剪、不改变帧排列。尺寸、透明通道及全部动画帧占用检查通过。此适配涉及缩放；若提交审核严格要求 H-7 的生成器原始尺寸，请在生成器选择 3 倍导出后重新提供原始文件。

所有素材引用仓库共享资源，没有修改共享代码、项目配置或示例。

制作和验证过程的临时脚本、日志、预览及重复图集已清理。场景直接通过 Godot 编辑；房间与玄关已验证巡游点连通性、全天对话、玩家池塘碰撞、NPC 移动、对话开启与关闭、两方向出口跳转。

已知共享问题：`shared/scene_portal/exit_portal.gd` 在物理回调中直接切换场景，且切换后访问已离开场景树的出口节点，因此切换时产生引擎报错。两方向跳转实际成功。该问题属于共享脚本，遵守 H-2、H-18 未修改它，需主办方统一修复。
